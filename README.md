# Papuga

Papuga — це менюбар-утиліта для macOS, яка рятує текст, набраний не тією розкладкою.
Виділив «ghbdsn», дав команду — отримав «привіт». Без ритуалів, без копіпаст-акробатики.

А ще Papuga вчиться на твоїх помилках: ловить неправильну розкладку **прямо під час набору**, збирає типові одруки в окремому екрані й допомагає прибрати їх назавжди — правилами, словником або (за бажанням) власним ChatGPT/Claude.

## Що вміє

### Перемикання вже набраного тексту
- Конвертує виділений текст між системними розкладками (в обидва боки).
- Працює з будь-якими активними keyboard layouts macOS — мапи будуються динамічно з системних input sources через Carbon `UCKeyTranslate`.
- Два режими результату: `Копіювати` або `Копіювати і вставити`.
- Зберігає і відновлює буфер обміну повністю (усі типи даних), тож твій кліпборд лишається цілим.
- Активація подвійним натисканням модифікатора (`Opt+Shift` за замовчуванням, також `Cmd+Shift`, `Ctrl+Shift`; інтервал 0.2–0.8 с) або власним хоткеєм через KeyboardShortcuts.

### Автозаміна під час набору (AutoFix)
- Визначає мову словесного острівця в реальному часі й виправляє «ghbdsn» на «привіт» прямо в полі — з grace-вікном на скасування (Backspace) і тостом-«сальто» біля курсора.
- Пресети чутливості: `Обмежено` / `Збалансовано` / `Більше підказок`, налаштовуване вікно скасування.
- Коли впевненість близька до порогу — показує пропозицію (Enter — прийняти, Esc — тимчасово закрити й мати 10 секунд на повернення) замість тихої заміни.
- Швидкий набір у хибній розкладці об'єднує в один інцидент до 30 слів або 300 UTF-16 одиниць і виправляє чи пропонує все речення однією безпечною заміною.
- Захист від хибних спрацювань: гард на орфографічні одруки, захист акронімів (API, QA, macOS, git…), політика перемикання розкладки (адаптивна / завжди / не чіпати).
- У редакторах коду (VS Code, Cursor, JetBrains, Xcode) показує пропозицію, а не мовчки замінює.
- Персональний блоклист: «не застосовувати у цих застосунках».

### Помилки введення + двигун прогнозу
- Окремий екран **Помилки введення** збирає одруки локально й аналізує їх фоновим prediction-двигуном: чанковий прохід у фоні, живий стрічковий фід знайдених пар «одрук → виправлення», дисковий кеш і донавчання на «доменному словнику», щоб твій жаргон і терміни перестали позначатись як помилки.
- Групування трьома способами: за застосунком, «інбоксом» і «родинами» (кластери схожих одруків) + добірка найчастіших помилок по застосунках.
- Швидкі дії прямо з рядка: створити правило автозаміни, додати слово в словник, «усі в словник» для застосунку.

### Покращити з AI (принеси свою модель)
- Кнопка **Покращити з AI** на екрані помилок відкриває покроковий флоу: згода → скопіювати згенерований промпт → вставити відповідь моделі → валідація → перегляд і застосування.
- Ти сам приносиш ChatGPT/Claude: Papuga лише формує промпт і **перевіряє** недовірену відповідь перед тим, як застосувати її до правил і словника — нічого не застосовується автоматично.
- Приватність за замовчуванням: згода вимкнена, увімкнено вичищання секретів із промпту.
- Зараз працює режим **«Вставити вручну (ChatGPT/Claude)»**; **Ollama** та **OpenRouter** позначені як «скоро».

### Словник, історія, копіопасти
- **Словник:** власні правила автозаміни (`джерело → ціль`, спрацьовують ще до мовного скорера) і список «не чіпати», який захищає терміни, ніки й команди.
- **Рішення Papuga:** локальний журнал лише корисних сигналів — замін, підказок, близьких до порога рішень, орфографічних варіантів, інцидентів розкладки та збоїв мутації. Очевидні перевірки рахуються лише анонімно, без тексту чи назви застосунку.
- **Копіопасти:** історія буфера обміну з пошуком, періодами, лімітами й відновленням запису просто з меню-бару.

### Аналітика та інструменти
- **Огляд:** економія часу, точність автозаміни, останні виправлення, графіки (Swift Charts).
- **Тест набору:** локальний тест швидкості з метриками WPM, CPM, точність і кількість помилок.

### Дрібниці, які тримають усе разом
- Анімована іконка в меню-барі (робить «сальто» після успішного перемикання); можна сховати.
- Меню-бар: перемикач AutoFix, лічильник заощаджених секунд, швидке відновлення буфера.
- Додаткові глобальні шорткати: перемикання, увімк/вимк AutoFix, відкрити Papuga, скасувати останнє виправлення.
- Онбординг із 4 кроків (вітання → Accessibility → Input Monitoring → готово).
- Автозапуск при вході в систему.

## Структура вікна

Окреме вікно Papuga з sidebar-навігацією:

- **Огляд** · **Рішення Papuga** · **Помилки введення** · **Словник** · **Копіопасти**
- **Налаштування:** Загальні · Мови · Правила (поведінка AutoFix) · Клавіші · AI · About
- **Інструменти:** Тест набору

> Власні правила `джерело → ціль` та список «не чіпати» живуть у **Словнику**, а вкладка **Правила** керує поведінкою автозаміни.

## Системні вимоги
- macOS 14.0+ (Sonoma або новіше)
- Дозвіл `Accessibility`
- Дозвіл `Input Monitoring`

Без цих дозволів гарячі клавіші, автозаміна й автоматичний copy/paste не працюватимуть стабільно.

## Як користуватися
1. Виділи текст у будь-якому застосунку.
2. Виклич перемикання: подвійним натисканням налаштованої комбінації або власним шорткатом.
3. Papuga скопіює виділене, сконвертує, вставить (або лишить у буфері — залежно від режиму) і переключить системну розкладку.

А для щоденного набору просто лиши увімкненою автозаміну — Papuga виправлятиме розкладку на льоту й складатиме список повторюваних одруків, щоб ти прибрав їх раз і назавжди.

## Встановлення

Завантаж останній DMG зі сторінки [GitHub Releases](https://github.com/rmarinsky/papuga/releases/latest), перетягни `papuga.app` в `/Applications`, запусти й дай дозволи `Accessibility` та `Input Monitoring`.

Подальші оновлення підтягуються автоматично через Sparkle — нічого додатково робити не треба.

Papuga безкоштовна й без підписок. Якщо вона тобі допомагає — у розділі About є посилання на донат.

## Локальний запуск для розробки
```bash
xcodebuild -resolvePackageDependencies -project papuga.xcodeproj -scheme papuga
xcodebuild -project papuga.xcodeproj -scheme papuga -configuration Debug build
```

Або просто відкрий `papuga.xcodeproj` в Xcode і запускай схему `papuga`.

Для швидкого dev-інсталу в `/Applications` (окремий app bundle + зручне тестування TCC-дозволів):
```bash
./scripts/dev-install.sh
```

## Релізи та автооновлення

Автооновлення працює через Sparkle і читає appcast з `https://rmarinsky.github.io/papuga/appcast.xml`.

Реліз триггериться **label-driven** з PR:

1. Відкрий PR у `main`.
2. Додай рівно один лейбл: `release:patch`, `release:minor`, `release:major` або `release:skip`.
3. Змерджи PR.

Далі CI сам: `prepare-release.yml` рахує наступну версію з останнього тега, пушить `vX.Y.Z`, далі `release.yml` білдить + нотаризує + підписує, створює GitHub Release і оновлює `appcast.xml` на гілці `gh-pages`. Версія застосунку береться **з тега** — `MARKETING_VERSION` у проекті лише плейсхолдер.

Ніколи не пушити в `main` напряму, не створювати теги `v*` руками, не редагувати `MARKETING_VERSION` чи `appcast.xml` вручну.

Локальний `./release.sh` бере версію з `git describe --tags` або зі змінної `RELEASE_VERSION`; для appcast потрібні `SPARKLE_EDDSA_PRIVATE_KEY` і `SPARKLE_DOWNLOAD_URL`.

## Технічний стек
- Swift + SwiftUI
- Розкладки — Carbon `UCKeyTranslate` (мапи символів напряму, без зовнішніх залежностей)
- [Defaults](https://github.com/sindresorhus/Defaults) — типізований UserDefaults
- [KeyboardShortcuts](https://github.com/sindresorhus/KeyboardShortcuts) — рекордер і хендлер шорткатів
- [LaunchAtLogin](https://github.com/sindresorhus/LaunchAtLogin-Modern) — автозапуск
- [Sparkle](https://sparkle-project.org) — автооновлення
- Swift Charts — графіки в аналітиці

## Коротко про філософію
Papuga не намагається бути «AI, що все зробить за вас».
Це маленький швидкий інструмент, який закриває одну болючу задачу дуже добре — а якщо захочеш, підключить *твою* модель, щоб добити рідкісні одруки. Локально, з твоєї згоди, без відправки чогось кудись за твоєю спиною.
